# Executive Summaries
Back to [[PMIT1027]] · Prev: [[Project Charters]] · Next: [[Project Scope]]

* A **short, stand-alone overview** of a larger document (charter, report, research)
* For busy, important stakeholders who may not read the rest - leaders sometimes **decide on the summary alone**

## Executive summary vs introduction
| Introduction | Executive summary |
| --- | --- |
| Sets the stage | **Condenses the whole document** |
| Explains scope, context and structure | Highlights problem, solution, value, conclusion |
| Orients the reader | Lets decision-makers skip to the essentials |
| *"This report will examine... structured as follows..."* | *"This document recommends a password manager... cut helpdesk tickets 40%... costs $25K, saves $60K... approval requested for Q3."* |

## Four core components
1. **Problem / need**
2. **Recommended solution**
3. **Value** of the solution (savings, uptime, satisfaction)
4. **Conclusion** - importance + next steps / the ask

### Example - failing email servers
| Component | Content |
| --- | --- |
| Problem | Outdated on-prem email servers crash often → downtime, lost productivity |
| Solution | Migrate to **Microsoft 365** cloud email |
| Value | Better uptime, lower maintenance cost, better collaboration tools, estimated savings |
| Conclusion | Approve the migration for a **Q3** rollout |

### Example - self-checkout (identify the parts)
* *Problem:* evening sales down 12%, long checkout lines · *Solution:* NCR FastLane self-checkouts · *Value:* halve wait times, recover ~$500K/year, +20% satisfaction, less overtime · *Conclusion:* phased rollout from the downtown store in Q4, all sites within 12 months

## Writing tips
* **Brief** (1-2 pages max)
* Focus on **outcomes and decisions**
* Avoid jargon and technical detail
* **Write it last, place it first**

## Exercise
* NAIT replacing aging labs with **600 laptops + cloud storage**, **$250,000 over 18 months**, retiring expensive desktops, enabling virtual lab access → write a 3-4 sentence summary covering all four components
