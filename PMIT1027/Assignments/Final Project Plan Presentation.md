# Final Project Plan Presentation
Back to [[PMIT1027]]

> [!info] Overview (10%)
> A light, fun **5-10 minute** team wrap-up of the [[Project Plan Report]] - every member speaks at least once - followed by Q&A.

## Required components
1. **Project summary** - purpose, goals, problem addressed
2. **Scope summary** - in vs out; **one significant scope decision/change**
3. **WBS** - top-level structure, major phases, key subtasks; one learning from building it
4. **Gantt / MS Project** - schedule, **critical path**, key dependencies; one MS Project insight
5. **Change management** - how CRs are submitted/reviewed/approved; show your CR form. 🎭 Act out **two fictional CRs** - one approved, one rejected
6. **Risk register** - two real risks + responses. 🎭 Add a **humorous bonus risk** (e.g. a teammate lost in an alien-conspiracy YouTube rabbit hole) and run a **risk response drill**
7. **Procurement** - 2-3 items, method + risks. 🎭 A mock "**bad procurement**" credit-card receipt from a retailer, contrasted with the consequences of skipping procurement
8. **Communication plan** - matrix overview. 🎭 Demo the **under-communicator** (vague) vs the **over-communicator** (word salad / overly technical)
9. **Question period** - be ready to defend the fun examples
