# Work Breakdown Structure Assessment
Back to [[PMIT1027]]

> [!info] Overview (10%)
> Break the project into manageable components with a WBS built in **Microsoft Excel** (not MS Project). Focus on **scope and task organization**, not scheduling.

## Requirements
* At least **three levels** below the title:
	* **Level 0** - project title/goal
	* **Level 1** - major deliverables, milestones or phases
	* **Level 2** - specific tasks per deliverable
	* **Level 3** - subtasks where needed
* Cover **all** work needed to reach the goal
* Columns: **WBS ID, Task Name, Owner, Duration (optional), Notes**
* Show hierarchy with **indentation or shading**
* Use **Data → Group** so sections collapse/expand
* Save as `Lastname_Firstname_WBS.xlsx`
* Follow the Brightspace example for structure/style
