# Project Plan Report
Back to [[PMIT1027]]

> [!info] Overview (20%)
> Integrate every planning document into one professional report (**~6-10 pages**, excluding appendices). Earlier work must be **reviewed and refined**, not just pasted in. AI may support research/ideas, but writing must be the group's own.

## Sections
| # | Section | Must include |
| --- | --- | --- |
| 1 | **Executive summary** | One concise paragraph - purpose, goals, outcomes |
| 2 | **Project overview** | Context, objectives, assumptions, constraints |
| 3 | **Scope statement** | In/out of scope |
| 4 | **WBS** | Final WBS, ≥ 3 levels, clear numbering (optional link to the Excel file) |
| 5 | **Project schedule** | Updated Gantt: start/end dates, milestones, dependencies (optional link to `.mpp`) |
| 6 | **RACI chart** | R/A/C/I for key tasks |
| 7 | **Change management plan** | How requests are submitted, reviewed, communicated + a custom **Change Request form** + one **sample CR** for your project |
| 8 | **Risk register** | **≥ 5** risks: statement, probability, impact, priority, mitigation, contingency, **owner**, monitoring |
| 9 | **Procurement plan** | **≥ 3** items: method (Direct/RFQ/RFP), rough cost (L/M/H), approvals, lead time/dependencies, risks |
| 10 | **Communication plan** | Who gets updates, how often, which channel (statement + matrix aligned with RACI) |
| - | Appendices (optional) | WBS diagram, Gantt, CR form, risk matrix |
