# Project Schedule
Back to [[PMIT1027]]

> [!info] Overview (10%)
> Turn the Excel WBS into a **Microsoft Project** Gantt schedule with durations, dependencies, resources and the **critical path**. **Must be `.mpp`** - other formats aren't accepted.

## Requirements
1. Revisit the WBS - note revisions, dependencies, changes
2. Assign **realistic durations** to every task/subtask
3. Set **dependencies** (predecessors)
4. Assign **resources** (team members, tools)
5. Highlight the **critical path** (Gantt/tracking view) - which tasks are critical vs which have flexibility (slack)
6. Clean, readable Gantt with no conflicts

## Deliverables
* **Written reflection**
	* Reintroduce the project
	* Summarize major tasks, dependencies, resources
	* **Critical path analysis** - which tasks and why
	* Justify scheduling decisions
	* Reflection questions: Which tasks have flexibility? What happens if a critical task slips? How did you keep it realistic? What did you learn about planning?
* **Screenshot** of the Gantt with task bars and critical path
* The **`.mpp`** file
