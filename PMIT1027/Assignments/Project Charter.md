# Project Charter
Back to [[PMIT1027]]

> [!info] Overview (10%)
> Team charter for the semester project using the **PMIT1027 Project Charter Template** (team name, project title, date, instructor + table of contents).

## Template sections
1. **Executive summary** - 1-3 paragraphs: purpose, major objectives, expected outcomes ([[Executive Summaries]]). What decision-makers read first
2. **Project purpose / description** - why, linked to organizational goals
3. **Objectives and success criteria** - **SMART**
4. **Stakeholders and roles** - sponsor, PM, team, users, suppliers
5. **Deliverables and milestones**
6. **High-level costs and revenues** - not a full budget
7. **Risks** - **at least 10**
8. **Assumptions and constraints**

## Checklist
- [ ] Every objective is SMART
- [ ] Success criteria answer "how do we know we're done?"
- [ ] Stakeholders identified early, with roles
- [ ] 10+ risks
- [ ] Executive summary written **last**, placed **first**
