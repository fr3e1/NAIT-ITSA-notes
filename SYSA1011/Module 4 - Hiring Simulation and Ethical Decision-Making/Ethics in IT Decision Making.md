# Ethics in IT Decision Making
Back to [[SYSA1011]] · Prev: [[Resume Workshop and Job Posting Analysis]] · Next: [[Conflict of Interest and Disclosure]]

> Making professional decisions when the answer is not always obvious.

## Opening situation
* Troubleshooting a server, you find **executive salary files**. Nobody knows. Open them, ignore them, say nothing, or something else?

## Competing priorities
| | vs | |
| --- | --- | --- |
| Privacy | | Curiosity |
| Security | | Convenience |
| Honesty | | Self-protection |
| Policy | | Personal relationships |

### Quick decisions
* Find confidential info while troubleshooting and **immediately close it** - ✅ appropriate (consider whether to report the exposure)
* Send an **AI-drafted client email without reviewing it** - ❌ you're responsible for what's sent
* Take home a monitor headed for recycling **without asking** - ❌ still company property
* Use the **company laptop after hours for freelance work** - ❌ misuse of resources + possible conflict of interest

## Your role in IT
* Access to employee info, payroll, student records, customer info, security systems, admin privileges
* > **Trust is part of the job** - access = responsibility

## Decision framework (used all semester + Assessment 2)
1. **What is happening?**
2. **Who is affected?**
3. **What risks exist?**
4. **What options are available?**
5. **What action would you take?**

## Scenarios
### Helping a coworker
* A "coworker" on Teams forgot their phone and asks for a password reset **without verification**. You know them and help. The account was **compromised**
* Lessons: **always verify identity** (social engineering exploits helpfulness); good intent doesn't erase impact; safeguards = verification procedures, callbacks, MFA

### The emergency change
* Critical server down, hundreds affected; a senior admin asks you to **bypass change approval**. It works
* Does success justify it? What if it made things worse? Afterwards you still owe **documentation** and a retroactive/emergency change record - use the **emergency change process** rather than skipping process entirely

## AI in workplace decisions
| AI can | AI cannot |
| --- | --- |
| Draft communications | Accept responsibility |
| Suggest solutions | Understand workplace context |
| Generate documentation | Replace professional judgment |
| Assist troubleshooting | |

* AI recommends **disabling a security feature** and it works → verify, assess risk, get approval first
* AI-generated report reviewed before submission → disclosure depends on policy; **you own any errors**
* > The question isn't *whether* to use AI - it's **who remains responsible** for the final decision

## What employers expect
* **Honesty** (transparent communication/reporting) · **Accountability** (own decisions and outcomes) · **Respect** (colleagues, data, systems) · **Privacy** (protect sensitive info) · **Competence** (professional standards)
* Found in workplace policies and professional codes (e.g. the **ACM Code of Ethics**)

## Professional judgment
* Managing risk, balancing priorities, following procedures, exercising judgment, accepting responsibility

## Key takeaways
1. **Access = responsibility**
2. **Use the framework**
3. **Intent and outcome both matter** - decisions are judged on process and results
4. **AI requires human oversight**
